Critical Section Criteria

  • 1. Mutual Exclusion: Only 1 thread in CS at any time.
  • 2. Progress: Selection cannot be postponed indefinitely if CS is free.
  • 3. Bounded Waiting: Bound on turns granted to other threads before request fulfilled.

Coffman's 4 Conditions

  • 1. Mutual Exclusion: Non-shareable resource.
  • 2. Hold and Wait: Holding one, asking for another.
  • 3. No Preemption: Resources released voluntarily.
  • 4. Circular Wait: {P0→P1→...→Pn→P0}.

Mutex vs Semaphore

  • Mutex: Locking mechanism owned by thread. Only owner can unlock.
  • Binary Semaphore: Integer flag (0/1); signaling between threads.
  • Counting: Permits up to N concurrent holders.

Deadlock Strategies

  • Prevention: Invalidate at least one Coffman condition.
  • Avoidance: Banker's algorithm (stay in Safe State).
  • Detection & Recovery: RAG cycle check, kill/preempt.
  • Ostrich: Ignore (used in general OS like Linux).

Top Operating Systems Viva Questions & Answers

Q1. What is a race condition and how did ThreadLock simulate a lost update? ↓

A race condition occurs when concurrent threads execute overlapping reads and writes to shared memory without synchronization, causing non-deterministic outcomes. In ThreadLock's simulation, T1 and T2 both read counter value 5 into local registers. Before T1 can write back 6, T2 computes 6 and writes. T1 then overwrites with 6, completely losing one increment (final value 6 instead of 7).

Q2. Is an "Unsafe State" in Banker's algorithm identical to a "Deadlock"? ↓

No. An unsafe state does NOT guarantee a deadlock has occurred; it simply means the operating system can no longer prevent processes from deadlocking if every process suddenly requests its declared maximum resource demand. A safe state guarantees a sequence exists where every process can terminate.

Q3. How do you prevent circular wait in the Dining Philosophers problem? ↓

Circular wait can be broken by: 1) Asymmetric solution: Odd philosophers pick left fork first, even philosophers pick right fork first. 2) Resource ordering: Philosophers must pick lower-numbered fork before higher-numbered fork (Dijkstra's hierarchy). 3) Arbitrator / Monitor: Allow at most 4 philosophers to sit at the 5-chair table simultaneously.

Q4. What is the role of empty, full, and mutex in Bounded Buffer? ↓

- empty: Counting semaphore initialized to buffer size N (tracks vacant slots; producer decrements).
- full: Counting semaphore initialized to 0 (tracks filled items; consumer decrements).
- mutex: Binary semaphore (initialized to 1) guaranteeing mutual exclusion when appending or removing from the buffer queue.
